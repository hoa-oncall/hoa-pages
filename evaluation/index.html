How to read this comparison

Existing ranking (baseline): communities ordered by the existing report’s stored efficiency scores, copied without recalculation. Choosing this order sorts the same complete table; it does not switch reports or hide columns. AI-enriched ranking uses those scores plus accepted new amenity evidence. If only a few ranks differ, switching orders will look almost identical.

Acceptance: at least two independent listings, high confidence with source text, support from at least 50% of analyzed listings, an approved category weight, and no mapping, count-conflict, or private-property review flag. Each listing votes once using its latest normalized extraction. An unmentioned amenity is unknown, not absent.

Score change: added category weight × scale factor ÷ (monthly fee per square foot × 100). Counts and attribute values are shown as evidence; they do not multiply scores. Unknown categories and legacy consensus attributes are display-only. Ranking ties use value score, then stable community ID.

Limits: listing claims are not independently verified. These scores do not measure reserve balances, special assessments, deferred maintenance, or litigation. A rank change can reflect other communities gaining points even when this community’s own score stays unchanged.
